# 성준이 공부방

초5 성준이의 2026 겨울방학 한 달(30일) 공부방입니다. 하루에 여섯 과목을 조금씩 합니다.

배포 주소: https://biblia1eunsu.github.io/sungjun-study/sj1122-room/

## 하루 구성

| 과목 | 내용 |

| 수학 | 최상위 사고력 3문제. 초5 복습(분수·소수·도형·약수배수) + 초6 1학기·2학기 선행(분수·소수 나눗셈, 비와 비율, 비례식, 원, 입체도형, 속력). 문항마다 힌트와 자세한 풀이 |

1일차부터 30일차까지 실제 문제와 지문이 모두 채워져 있습니다. 1~14일차는 초5 복습과 초6 1학기 선행, 15~30일차는 배운 것을 다시 쓰는 심화·정리 흐름입니다.

## 앱 기능

- 상단에 오늘의 진행률(완료 과목 수/6), 연속 학습일, 날짜별 기록
- 진행 상황은 브라우저 `localStorage` 에 날짜별로 저장됩니다.
- 갤럭시 크롬에서 홈 화면에 추가하면 `성준이 공부방` 이름과 아이콘으로 전체 화면 실행(PWA)
- 다크 모드 지원
- 6과목을 모두 끝내거나 하단 버튼을 누르면 ntfy.sh 로 엄마 폰에 알림

## 고치기

학습 내용은 `data/dayNN.js` 의 배열 하나를 고치면 됩니다. 문제는 `q`(질문), `hint`(힌트), `answer`(허용 정답 배열), `solution`(풀이) 로 이루어집니다. 퀴즈는 `choices` 중 `answer` 번째가 정답입니다. 국어는 `korean.grammar`(문법·어휘 포인트 + 확인 퀴즈)와 `korean.reading`(문학·비문학 지문 + 독해 퀴즈 2문항)으로 이루어집니다.

화면을 고친 뒤에는 `sw.js` 의 `CACHE` 이름을 한 단계 올리면 이미 앱을 설치한 기기에서도 새 화면으로 바뀝니다.

## 국어영상(김주혜 국어) 목록 관리

`data/shorts.js` 의 `videos` 배열이 곧 하루 1편 순서입니다. 채널(@kimjuhea0418) 쇼츠 탭에 올라온 순서(최신 → 과거)를 그대로 담았고, 첫 영상이 은수 님이 보내 주신 `ovQEHeeG1zE`「상자에 갇힌 사람과 나무」입니다. 새 영상이 올라오면 배열 맨 앞에 `{ id: "영상ID", t: "제목" }` 한 줄을 넣으면 다음 날부터 그 영상부터 나옵니다. 앱은 localStorage 의 `shorts.watched` 에 본 영상 ID와 날짜를 남깁니다.
