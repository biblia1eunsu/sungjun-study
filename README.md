# 성준이 공부방

초5 성준이의 2026 겨울방학 2주 공부방입니다. 하루에 다섯 과목을 조금씩 합니다.

배포 주소: https://biblia1eunsu.github.io/sungjun-study/

## 하루 구성

| 과목 | 내용 |
| --- | --- |
| 수학 | 최상위 사고력 3문제. 초5 복습(분수·소수·도형·약수배수) + 초6 1학기 선행(분수·소수 나눗셈, 비와 비율, 비례식). 문항마다 힌트와 자세한 풀이 |
| 영어 | 2027년 1월 발리 여행 대비 여행 영어 5문장(발음 듣기 포함) + 주니어 영자신문 1편(문장별 해석, 핵심 단어 5개, 독해 퀴즈 2문항) |
| 한국사 | EBS 초등 스토리 한국사 강좌와 유튜브 검색으로 이어지는 시대별 학습 + 핵심 퀴즈 10문항 즉시 채점 |
| 위인 | 오늘의 인물 1명의 업적 정리 + 확인 퀴즈 2문항 |
| 과학 | 과학·시사 상식 1분 읽기 + OX·객관식 퀴즈 2문항 |

1일차부터 14일차까지 실제 문제와 지문이 모두 채워져 있습니다.

## 앱 기능

- 상단에 오늘의 진행률(완료 과목 수/5), 연속 학습일, 날짜별 기록
- 진행 상황은 브라우저 `localStorage` 에 날짜별로 저장됩니다.
- 갤럭시 크롬에서 홈 화면에 추가하면 `성준이 공부방` 이름과 아이콘으로 전체 화면 실행(PWA)
- 다크 모드 지원
- 5과목을 모두 끝내거나 하단 버튼을 누르면 ntfy.sh 로 엄마 폰에 알림

## 알림 토픽

- 엄마 알림: `biblia-sj-mom-202611` (https://ntfy.sh/biblia-sj-mom-202611)
- 성준이 알림: `biblia-sj-kid-202611` (https://ntfy.sh/biblia-sj-kid-202611)

앱은 완료 시 `biblia-sj-mom-202611` 로 과목 요약을 POST 합니다. 제목 헤더는 ASCII(`Study Complete`)로 보내고 본문에 한글 요약을 담습니다.

## 파일 구성

```
index.html        화면 구조
styles.css        디자인(라이트/다크)
app.js            진행률·채점·저장·음성·알림
manifest.json     PWA 설정
sw.js             오프라인 캐시
data/day01~14.js  하루치 학습 내용
icon-*.png        앱 아이콘
```

## 고치기

학습 내용은 `data/dayNN.js` 의 배열 하나를 고치면 됩니다. 문제는 `q`(질문), `hint`(힌트), `answer`(허용 정답 배열), `solution`(풀이) 로 이루어집니다. 퀴즈는 `choices` 중 `answer` 번째가 정답입니다.

화면을 고친 뒤에는 `sw.js` 의 `CACHE` 이름을 한 단계 올리면 이미 앱을 설치한 기기에서도 새 화면으로 바뀝니다.
